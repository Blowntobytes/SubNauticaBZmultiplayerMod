BZMultiplayer 0.9.26 - Subnautica: Below Zero multiplayer (Steam only)
All-in-one: includes BepInEx 5.4.23 (Tobey's BepInEx Pack for Below Zero) + the multiplayer mod.

INSTALL (2 minutes)
1. Find your game folder: Steam -> Library -> right-click "Subnautica: Below Zero" -> Manage ->
   Browse local files. You should see SubnauticaZero.exe there.
2. Extract EVERYTHING in this zip straight into that folder. If Windows asks to merge/replace a
   BepInEx folder, say yes. Afterwards the game folder must contain BOTH of these:
       <game folder>\winhttp.dll
       <game folder>\BepInEx\plugins\BZMultiplayer\BZMultiplayer.dll
3. Launch the game once from Steam and quit again (BepInEx creates its config files on first run).
4. Optional, VR only: SubmersedVR_BZ from github.com/jbusfield/SubmersedVR_BZ. Not needed for flat-screen.

No save copying needed: the host's world is sent to you automatically when you join.

PLAY
- Host loads their save, is in-game, and presses F11.
- You sit at the MAIN MENU and press F4. The mod finds your friend hosting, joins, downloads their
  world (takes a few seconds) and loads it. It goes into save slot "slot9990" on your machine and is
  overwritten on every join, so don't use that slot for your own game.
  (If it can't find a friend hosting, F4 joins a lobby id pasted in your clipboard instead.)
- End leaves the session. Home asks the host to resend the world.
A small status box appears top-left of the desktop game window (not visible in a headset).

You must both be on Steam and on each other's friends list, on the same mod version.
Log file if something goes wrong: <game folder>\BepInEx\LogOutput.log
